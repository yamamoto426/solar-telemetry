# SolarGuard Telemetry Pro

PWA de telemetría solar (simulador) y centro de seguridad eléctrica.
Funciona en Android y iPhone, se instala desde el navegador y abre sin internet.

## Publicar
GitHub → Settings → Pages → Branch: main / root.

## Seguridad
Las claves van en `.env` (ignorado por Git). Nunca subir claves, tokens ni bases de datos.
